同一网格的五套皮肤分别保存人物与道具透明层，共用一份与动作绑定的遮挡高亮灰度层及地面阴影层。母版为 1080×1080 / 30fps / 8 秒 / 240 帧；t=8 的第 240 帧单独用于接缝 QA，不进入正式序列。派生视频为 720×720 H.264、8 秒、240 帧、无音轨。高亮开关、颜色、亮度与背景均由脚本从同一母版合成；不生成镜像。

统一取景取五套皮肤全片人物和道具 alpha 的并集，加固定留白；视频、封面、缩略图及关键帧使用同一配方。正式视频默认高亮开，拼图及顶峰对照同时展示开和关。需要另一套视频参数可用独立 `--derivative-set` 合成，既有成片和配方拒绝覆盖。

## 已发现并修正的问题

1. 支撑手的接触高度不能沿用旧模型的骨点近似。现对新手及指骨的可见索引网格完整测量，每侧 11,445 顶点；实际垫顶为 y=0，厚度向下铺设。最终标定手表面最小间隙目标为 +0.5 mm。
2. 旧 `floor.at` 表示腕 x/z，把它直接转为 `palmAt` 会移动腕及躯干、丢失支撑锁。臀桥与猫牛保留腕 x/z 和支撑锁，采用明确的新版掌形；猫牛肩中心抬高约 10.94 mm，使新模型双肘保持接近伸直，同时保留膝脚支点。蛙式保留原放松手形，只校准掌面高度。
3. 普通阴影深度材质不能代表自定义呼吸/服装变形。分层渲染复制当前材质实际顶点着色程序，并用位移探针检查阴影响应；高亮灰度与材质色、灯光和脉冲独立，人物与道具遮挡仍参与深度测试。
4. 旧 QA 的 `frames:0` 与只采样 Hand 骨不能作为新版手指通过证据；新检查完整覆盖可见手/指网格，发布门禁拒绝空 QA。
5. 单侧与计次须按实际时间线解释：椅子和弯举片内右先左后，每次单侧算一次；臀桥本片为左脚支撑，每侧默认十次、五循环后提示换侧，不假称每个循环都换侧，也不伪造另一侧素材。蛙式是后坐回程，猫牛八秒含两个完整四秒循环。
