# Flare训练人物基准 training-human-v2

用户于2026-10-12指定，本次肩颈修复后的人体作为后续动作的统一标杆。新动作采用此版本；此前演示成片保留，等用户安排再使用新版本另行重渲。

这是一套完整渲染人体配置，包含已有Snow派生网格、灰色人台头、原服装与骨架、主题和肩颈蒙皮。基础GLB继续使用App正式训练源的 `c14683e4…`，本次不是用另一份人体替代原成熟网格。版本身份及完整来源哈希见 [模型清单](../tools/drill-anim/models/training-human-v2.json)。Snow与头部参考的授权链继续见原署名。

专项支撑中，原衣领混合了头骨与肩骨的权重，肩部下移时形成方形平台；颈部还绘制了一层重复衣领。本版本让现有衣领与颈部采用连续的肩颈蒙皮，皮肤保持灰色，真实上衣保持可见。网格位置、法线、UV、拓扑、骨架关节及人体比例保留，动作支点、髋部、腿轨迹、节奏和镜头由各动作独立定义。

```javascript
export default {
  id: 'new-drill-id',
  modelProfile: 'training-human-v2',
  alignClavicles: false,
  // 此处填写动作时间线、姿态、镜头、高亮与QA。
};
```

普通drill-anim启动会加载 `page/training-collar.js`，引擎按 `modelProfile` 启用配置。未指定profile的旧规格沿用 `legacy-v7`；这保护历史重现，并不表示后续新动作可省略版本字段。以后重渲旧动作时显式选择新profile、另存版本与输出，保留原媒体与参数。

配置首次以实际CPU蒙皮中立坐标缓存局部权重，兼容共享交错缓冲区；重复播放不重建，切回旧profile精确恢复原权重和材质回调。真实上衣、头、光照、描边和透明度保持，手脚及其他网格不参与肩颈修正。

本轮实现与具体检查见 [专项App人物修复记录](thomas-app-model-v3-2026-10-12.md)。后续改变此版本的外观来源或肩颈配置应创建新人体版本和验证记录，不能静默改动同一版本。当前App仍为L43，旧51项视频没有重渲或替换。
