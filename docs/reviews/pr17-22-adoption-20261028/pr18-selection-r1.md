# PR #18 侧抬腿：可复用部分选择（待 r7 实测）

对照 main 的 `drill-anim/specs/h-side-leg-raise.js`、冻结的 `drill-anim/page/engine.js`，以及 PR #18 head `cb3859c` 的 `h-side-leg-raise-r2` 至 `r5`，选择两个与人体具体毫米尺寸无关的求解处理。此处是局部候选，并非动作或接触验收。

1. 原动作的求解变量为 `px, py, pz`；约束只有左腿 reach 和骨盆 X 位置。reach 距离受到前后偏移影响，但没有独立的前后位置目标，因此 `pz` 在这组约束中欠约束；PR #18 r3 记录冷、热启动收敛分支不同。保留 `px`、`py`、原约束与骨盆初始位置，仅从变量及正则项移除 `pz`，固定原作者的前后平面。此判断来自求解结构和原 PR 说明，不是本次对 r7 已复现冷、热漂移的声明。
2. 两手原用 `touch.solve: 'bisect'`。冻结引擎只采集固定名称的代理网格；未找到法线时最多向腰推进 8 次、每次 15 mm，仍找不到就返回 0，且没有恢复手腕。`docs/pr15-contact-repair-20261023.md` 记录旧 v2plus 上左右各 120 mm 的实测反例；r7 的新躯干也不能仅凭旧代理网格假定已覆盖。移除两手的求解 `touch` 可避免该失败路径，保留原 hips-frame 掌心目标、方向及 `qa.touch`。这不等于保证真实手掌贴肤或不穿模。

`tools/body-v3/adoption-r1/prepare-spec-r1.mjs` 导出 `prepareReviewedSpec(spec)`：仅针对 `h-side-leg-raise` 和 `h-side-leg-raise-rN` 克隆后处理，其他动作返回原引用；源对象不改。输入结构不符合预期时显式失败。原时长、轨迹、鞋角、约束、其余目标和 QA 都不变。此函数不装入引擎；组合入口须在每次 `E.pose` 使用前调用，且保证重复准备不改变结果。已含旧版毫米校准的输入不会被本函数反向还原；本轮应使用 main 原动作，不能引入旧 r2–r5 规格当作依赖。

不采纳 r2 旧人体包装、r3 旧鞋角补偿或 r5 旧掌心毫米校准。这些依赖旧身体或旧鞋的测量，不可直接作为 r7 的结论。
