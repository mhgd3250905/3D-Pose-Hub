# PR #18 通用求解修法采纳 r2

2026-10-28，按用户“采纳独立优化，淘汰因新身体而过时的适配”的授权，只保留侧抬腿的两项通用处理，接入新的 r7 可选扩展；不整体合并旧 v2 规格包。原 PR head 为 `cb3859c813f934f6b0192b3b23eb82c124373e50`。[初选 r1](pr18-selection-r1.md)保留当时待实测状态，本记录补充实际 r7 复测。

## 采纳的行为

`prepareReviewedSpec()` 仅处理 `h-side-leg-raise` 及其 `-rN` 家族，克隆后移除求解变量／正则项 `pz` 和两手的求解 `touch`，保留原始轨迹、手部目标与朝向、鞋角、时长、约束及 `qa.touch`。其他动作返回原引用；输入结构异常显式失败，重复处理幂等。原 spec 和冻结引擎不改。

原约束没有独立前后位置目标，`pz` 存在不同的收敛分支；旧代理表面法线缺失还可能使 touch walker 推动手腕后不恢复。新扩展在每次 `E.pose` 前应用准备函数，卸载时恢复原包装。它没有导入 r2–r5 的旧身体包装、鞋角、踝高、掌心毫米偏移，或 RDL 臂腿够距校准。

## r7 上的实测

对同一个 main 原动作，在 `0、2、4、6、7.999 s` 分别冷启动及以 `pz=0.2 m` 热启动。原样输入的冷启动 `pz≈−43.448 mm`，热启动 `pz≈177.787 mm`；骨盆前后分支相差约 `221.235 mm`，高度也变化约 `16.976 mm`。原 touch 返回约 `−35.1…−39.5 mm`，该值来自旧代理求解，不能当作真实可见皮肤距离。

处理后五个时间点均不再求解 `pz`，骨盆前后偏移为原始平面 `0`；每个时间点的冷／热输出相同，两手求解 touch 为空，未出现新增求解告警。CPU 检查另证明只改上述字段、源对象未变、轨迹和 QA 保留。实际帧和机器摘要随 [PR #21 组合扩展复测](pr21-adoption-r1.md)保存。

此处验收的是欠约束分支与旧代理失败路径的消除。手掌对腰部的真实贴肤、完整鞋底接地及全动作外观仍需后续 r7 动作迁移逐项审核；本次不把移除旧求解器当作这些项目通过。原 PR 作为旧包被新扩展取代关闭，不删除源分支。
