## 复核 r8-gc1 的问题（生产安装链实测关节）
- 上侧手臂其实已在胸廓**横断面**内扫掠（扫掠面法向 ≈ 躯干轴，(up,out,fr)=(+0.97,−0.21,−0.08)）——`(sin a,0,cos a)` 是 rest 坐标系（Y=躯干轴），不是矢状面。
- 真正别扭的地方：胸廓只转 32°，手臂靠肩后伸 56.8°（相对胸廓冠状面）把手"拽"到身后，且手停在肩高水平（腕离地 0.38 m）；肘一直弯 23°；起始上侧手悬在下侧手臂上方约 11 cm，没有"搭在前臂上"。
