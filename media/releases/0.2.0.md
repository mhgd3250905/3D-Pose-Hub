## 来源与复用

规格绑定继承 v0.1.0，只有 h-quad-cars 改回原规格；其 r2 当时是高亮选区绕行，soft-v1 使用原规格更合适。另六项修订绑定保持：

| 动作 id | 规格 |
| --- | --- |
| h-knee-hug | drill-anim/specs/h-knee-hug-r2.js |
| h-supine-twist | drill-anim/specs/h-supine-twist-r2.js |
| s-seated-fold | drill-anim/specs/s-seated-fold-r3.js |
| s-frog | drill-anim/specs/s-frog-r2.js |
| s-9090 | drill-anim/specs/s-9090-r2.js |
| h-9090-liftoff | drill-anim/specs/h-9090-liftoff-r2.js |

46 项均物化为原 id、`fps:30`、`modelProfile:'training-human-v2'`、`alignClavicles:false`。RTX 4080 / ANGLE D3D11、PR2 2160² 原始采样，合成精确 1080 straight-alpha，再派生 `#101013` 深色 H.264 yuv420p / 30 fps / CRF18 / slow / 无音轨 / faststart。540² 封面按各规格海报时刻从成片提取，Lanczos 缩放、JPEG qscale 4。

按用户要求先核对了历史绿幕和透明帧。旧 glow-B/v7 母帧可直接用于同外观的换背景、缩小尺寸，但主体 RGB 已烘焙旧高亮，不能精确生成 soft-v1；本次只补渲所缺新母帧一次，绿幕、深色和封面共用该母帧。后续同外观的浅底和其他尺寸也可从本批 alpha 派生，不重复做 3D。原始帧、绿幕与 alpha 保留在 E 盘本机批次 `output/media-v0.2.0-soft-20261018/`；原有素材保留。

- 46/46 项完整动作 QA、绿幕合成 QA、全片 CPU 解码通过；共 11,220 个周期帧，触边帧为 0。每张 alpha 均可解码为非空 1080 RGBA，渲染 worker 日志通过执行保护检查。
- 46/46 深色视频再次完整 CPU 解码，逐项首/中/末像素合成检查、H.264 格式和帧数检查通过；46 张封面为真实 540 JPG。媒体与母帧逐文件大小、SHA-256 已复核。
- alpha 和最终视频分别对全部 11,220 帧在原始 1080 分辨率做青色时间差分扫描，包含循环首尾。执行层记录选中输入、扫描报告及 producer 的哈希绑定，并核对扫描前后输入不变；两个 pilot alpha 报告仅对未变的选中源复用。
- AI 实际查看全部 46 项的首/海报/中/末样本及非零 alpha 候选联系表；另查看深蹲蹲底、靠墙分腿等原始大图。最终编码视频的 14 项非零候选均另看邻帧联系表，共 244 帧；其余 32 项仅记录数值覆盖。所查范围未发现新增阻塞，不等同用户人工验收或全循环逐帧播放。
- 本地实包与云盘下载实包均完成：解压 → 按 lock 同步 92 文件 → 离线 `--check` 92 通过、0 漂移 → 重复同步 0 复制。云盘冻结清单也参与了实际同步检查。未实际在 Mac 上运行；Mac 使用相同标准库脚本。

扫描候选可能来自运动、遮挡和压缩，不直接等于坏帧数。检测只覆盖超过阈值的青色差分，不能证明鞋纹等其他颜色、亮度或较小变化在全片无闪烁。soft-v1 仍保留大面积高亮中的腿部分段线、青蛙式与臀桥部分轮廓偏利，以及坐姿、深层肌群或椅面遮挡时高亮可见范围较小的限制。
