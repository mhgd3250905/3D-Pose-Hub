# 2000 clipB 逐帧精标

来源为 2026-11-19 上传的 `11月19日 (5).mp4`，原片 SHA-256 为 `0034efb44437f300fa928c497c86411006ef1cefaeeff301f2824173ba827b33`。该哈希与 MotionLab 已有的 92 帧姿态恢复输入一致。图像为 1080 × 1080、30 fps，以原片 0 基编号 `00000` 至 `00091`，区间首尾均包含。

| 路径 | 内容 |
| --- | --- |
| `frames/` | 原始分辨率 RGB PNG，逐帧解码像素已与原视频核对。 |
| `kp2d/` | 全身、双手和脚关键点，模型置信度、遮挡及左右侧复核说明见目录 README。 |
| `depth/` | 逐帧 16 位 Video Depth Anything 相对逆深度，数值越大代表越近，量化比例与 Air Flare 一致。 |
| `mask/` | 与原图同尺寸的人物黑白蒙版。 |
| `kp3d/` | GVHMR 相机与估计世界坐标下各 24 个关节，含 SMPL-X 局部旋转、根姿态和 10 个体型参数。 |
| `labels.txt` | 人工支撑、叠手和旋转标注，含遮挡和不确定边界。 |
| `labels/background_tracking.csv` | 对齐原帧号的背景跟踪变换及可靠性字段。 |
| `SHA256SUMS.txt` | 同目录数据文件的 SHA-256 清单。 |

图像原点为左上角。3D 相机坐标 x 向右、y 向下、z 向前，世界坐标 y 向上，数值使用单目估计模型尺度。模型估计 `fx=fy=1527.35 px`、`cx=cy=540 px`，畸变与真实尺度未知。旋转为弧度轴角，手部接触和速度以原片及人工标注复核。3D 中最大的相机坐标帧间跳变在第 20→21 帧的左脚，约 0.375 模型米。
