# 2000 clipA01 逐帧精标

来源为 Suraj Raut 的 [2000 spin tutorial](https://www.youtube.com/shorts/GYJ-mjdkFT0)。使用交接提交 `acecf397` 中的原文件，SHA-256 为 `88c0b80bd61fe702e155d87585c322816c8b61a7d6c02b0afa2434e26a65b00d`。原片为 604 × 1080，标称 30000/1001 fps。所有逐帧数据沿用原片的 0 基编号。

完整示范位于标有 “Done” 的末段。截取从 `00384` 至 `00612` 共 229 帧，首尾包含。片头从入转中开始，中段是分解练习，末段保留了站姿起势、撑地、叠手旋转、落地和起身。`source-00384-00612.mp4` 是同尺寸无声逐帧无损切片，切片和 PNG 的 RGB 解码逐帧与原片一致。

| 路径 | 内容 |
| --- | --- |
| `frames/` | 原分辨率 RGB PNG。 |
| `kp2d/` | 全身、双手和脚关键点，包括模型置信度及遮挡复核说明。 |
| `depth/` | 逐帧 16 位 Video Depth Anything 相对逆深度，数值越大代表越近，量化方式见目录 README。 |
| `mask/` | 与原图同尺寸的人物黑白蒙版。 |
| `kp3d/` | GVHMR 相机和估计世界坐标下各 24 个关节，含 SMPL-X 局部旋转、根姿态和 10 个体型参数。 |
| `labels.txt` | 人工支撑、叠手和旋转标注，含遮挡和不确定边界。 |
| `labels/background_tracking.csv` | 对齐原帧号的背景跟踪变换及可靠性字段。 |
| `SHA256SUMS.txt` | 同目录数据文件的 SHA-256 清单。 |

2D 图像坐标原点在左上角。3D 相机坐标 x 向右、y 向下、z 向前，世界坐标 y 向上，数值使用单目估计模型尺度。`kp3d` 的原片时间来自源视频画面时间戳。旋转为弧度轴角。模型估计的相机内参为 `fx=fy=1237.42 px`、`cx=302 px`、`cy=540 px`。叠手中 `00512→00513` 的相机坐标左手出现约 0.558 模型米的估计跳变。判断支撑和左右侧时请对照原图及人工标注。
