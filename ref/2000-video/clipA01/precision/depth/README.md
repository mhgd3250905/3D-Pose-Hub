# clipA01 相对深度

`00384.png` 至 `00612.png` 共 229 张单通道 16 位灰度 PNG。每张 604 × 1080，按原片帧号与 `../frames/` 同名图像逐像素对齐。

像素值越大表示越近。量化沿用 Air Flare 的步长 `0.00013642363847689033` 和零偏移。Clip A01 的模型原始相对逆深度范围约为 `0` 至 `22.383837`，直接编码会超出范围。编码前对整段统一乘以 `0.39941870774653848`，再用上述步长量化。Clip B 的归一化乘数为 `1`。

- 归一化相对逆深度约为 `uint16 × 0.00013642363847689033`。
- 原始模型相对逆深度约为 `uint16 × 0.00034155545504258527`，即将归一化值除以 `0.39941870774653848`。

深度值无量纲，各切片的模型尺度独立，无法直接比较绝对尺度。叠手、并腿和快速旋转时，遮挡处和轮廓附近可能有估计偏差。
