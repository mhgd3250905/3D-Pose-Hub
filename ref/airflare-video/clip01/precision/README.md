# Air Flare clip01 逐帧参考数据

草地斜侧镜头来自 Simonster Strength 的 [Airflare 教学](https://www.youtube.com/watch?v=1fxOuGQcEsI)。原片从 0 开始编号，交付 `10118` 至 `10273` 共 156 帧，右边界 `10274` 不含。原片 1920 × 1080、30 fps。所有逐帧数据用同一个原片帧号。相对切片的帧号为 `source_frame - 10118`。

| 路径 | 内容 |
| --- | --- |
| `frames/` | 1920 × 1080 RGB PNG，与无损切片逐帧解码校验一致。 |
| `kp2d/` | 原图像素坐标的全身、手和脚关键点。 |
| `depth/` | Video Depth Anything Small 估计的相对逆深度，16 位灰度 PNG，与原图像素对齐。 |
| `mask/` | 白色为演示者，黑色为背景。 |
| `kp3d/` | 每帧 24 个 SMPL 关节的相机与估计世界坐标，以及 21 个 SMPL-X 局部旋转、根姿态和 10 个体型参数。 |
| `labels.txt` | 人工判读的左右手脚接地、三圈相位、地面参考点和不确定边界。 |
| `labels/` | 背景逐帧跟踪矩阵以及质量字段。 |

`depth/README.md` 记录全片共用的量化比例。像素值越大表示越近，数值无米制单位，人物轮廓附近可能有估计误差。

## 图像和相机坐标

像素坐标原点是图像左上角，x 向右，y 向下。`kp3d` 的相机坐标 x 向右、y 向下、z 向前，使用单目模型尺度。估计世界坐标沿用 GVHMR 的 y 向上输出。旋转为弧度轴角向量。`betas` 随每帧的姿态一起保存，模型未测得表演者真实身高。

固定机位模式的估计内参为 `fx = fy = 2202.91 px`，`cx = 960 px`，`cy = 540 px`，对应约 `47.09°` 水平视角。焦距由流程启发式给出，视频没有校准值或可核实的畸变系数。背景跟踪测得约 48 像素的画面漂移。`labels/background_tracking.csv` 中的 `frame_to_ref` 可将当前帧的原始像素坐标映射到第 `10118` 帧。独立背景点的逐帧中位误差，全段中位数为 0.40 像素，最高为 2.24 像素。场景有视差，矩阵用于图像稳定。

以原片画面确认换手、着地与左右侧。GVHMR/HMR2 在 `10221→10222` 有一次明显的足部估计跳变。原片缺少已核实的同次动作第二机位，步道上的四个参考点也不能确定草地的三维比例尺。
