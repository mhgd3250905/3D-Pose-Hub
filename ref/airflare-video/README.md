## 教学要点和常见错误

- [02:15–02:45](https://www.youtube.com/watch?v=1fxOuGQcEsI&t=135s) 用入式借势，移到一侧单手 pike 支撑，胸口转向上方，经腾空星形过渡到另一手接撑，再双手过渡回起始侧。作者示范躯干大约倾斜 45°，角度可因技术而异。
- [04:32–04:45](https://www.youtube.com/watch?v=1fxOuGQcEsI&t=272s) 常见错误是领腿往后踢，把双腿带向地面。髋过伸会使接手时重心落不到支撑上方。
- [04:51–05:05](https://www.youtube.com/watch?v=1fxOuGQcEsI&t=291s) 自由臂横过身体，腾空形成星形。作者示范腕旋前和上臂内旋，以便接手后继续转体。
- [05:21–05:59](https://www.youtube.com/watch?v=1fxOuGQcEsI&t=321s) 接手时保持抬髋，双腿沿圆弧维持动量。回到 pike 时腿贴近地面扫过，起跳前右腿向侧方横扫。

## 数据

草地段另有[原片帧号对齐的逐帧数据](clip01/precision/)，包括原始 PNG、全身和手脚关键点、深度、人物蒙版、相机坐标三维姿态、触地相位和背景跟踪矩阵。

每段包括 `pose_details.json`、`joints_3d_all.csv`、`body_rotations_axis_angle.csv`、`root_motion.csv`、`pose_parameters.npz`、`overlay_2d.mp4` 和 `contact_sheet.jpg`。关联的轨迹元数据、2D 关键点及骨架 NPZ 与 MotionLab 的 clip01 同结构。CSV 和模型参数按无损切片的 0 基帧编号对齐。

GVHMR/HMR2 使用固定摄像机模式。叠加图是二维估计，三维关节与根运动来自单目模型。视频未提供相机标定或人体尺度，倒立与自遮挡时尤其要对照原片核验左右侧、深度和手掌接触。

二维左右侧稳定步骤分别调整了 33/156 帧和 24/169 帧。草地段第 66 帧的叠加图可见腿部关键点偏离，三维估计在第 102→103 帧出现明显足部跳变。验收换手和接地时以原片为准。
