## 本机实证与限度

Windows、隔离工作树、Vite + Chromium 实际 WebGL 上运行。8 项共 106 个原始关键/中间帧进行了穿地、固定点、自碰撞、手部、肢体角度和关节限位指标初筛，除上述直度问题外未见其他失败。检查了实际人物及椅子图。

修复后的鸟狗与游泳分别重新采集完整 240 帧几何及手部指标，交给原 `lib/qa.py` 计算。两项 `frames_complete=true`、几何 `pass=true`，求解警告均为 0；鸟狗左肘保持期最小 176.96°、右膝 178.05°，支撑右肘最小 178.07°；游泳双肘最小 175.50°。穿地最低分别 -0.1 mm / +0.7 mm（容差 -2 mm），固定点最大漂移 0 mm，自碰撞及手部指标通过。未生成新 MP4/GIF，也没有成片合成后的画面边界 `edge-*` 数据；这里的几何通过不代表成片验收。

根目录 `npm ci` 和 `npm run build` 通过（既有大包体提示）。新动作的 verifier 归属由主线统一登记，本审核未修改 verifier。

原始及修复后的指标、实际截图和运行辅助脚本位于本次隔离工作树忽略的 `output/pr105/`；不作为生产资源提交。修复仅更改两个 spec 参数与 QA 条件。原作者的历史成片需保留；这两个动作的旧成片不能冒充修复后渲染结果。
