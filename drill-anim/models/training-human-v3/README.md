# training-human-v3 (phase 1 candidate, for review)

Body proportions fixed per `proportion-audit.md`:
- upper arm ×1.256 (0.322 m), forearm ×1.108 (0.253 m);
- thigh ×1.161, shank ×1.017;
- trunk (pelvis → torso pivot) shortened by 64 mm, so shoulder, head and stature are unchanged (1.729 m).

Standing fingertip height ≈ 0.64 m, against a norm of ≈ 0.65 m.

## How it is built (no frozen file edited)
- `runtime/public/coach-v3/coach-rig-v3.json`: generated by `tools/body-v3/make_rig_v3.py` from the frozen rig.
- `runtime/src/body-warp-v3.js`: proportion warp.
  - Segment bones stretch linearly along their axis, continuous at shoulder, elbow, wrist, hip and knee, so there is no stretch band at the joints.
  - End bones move rigidly.
  - Applied through each vertex's real skinning matrix. The glb is quantized; positions are rewritten as float.
  - Inverse bind matrices are corrected so the rest pose is preserved.
- `runtime/src/viewer-v3.js`: copy of viewer.js. It loads the v3 rig and warps the glb before `createCoachMotion`, so the stock `coach-motion.js` solves with v3 lengths. Frozen `viewer.js` / `coach-motion.js` are untouched.
- `boot-v3.mjs`: copy of `lib/boot.mjs`. It routes `/src/viewer.js` to `viewer-v3.js` in the headless page.
- `loader.mjs` `applyV3(page, spec, {handScale})`:
  - loads v2plus torso/limbs and r8 hands warped with the same mapping in their reset pose (`tools/body-v3/reset-joints-v2.json`);
  - moves the compression cuff planes;
  - adds r8 rig/poses and the r5 wrist-twist runtime;
  - `handScale` (e.g. 1.18) is for comparison only.
- `human-v3.js`: copy of `page/human-v2plus.js` for v3 material work.

The glb binary is not rebuilt. Blender was not needed: the warp is applied in-page at boot from the frozen glb. A baked `flare-coach-v3.glb` can be exported later if wanted.
