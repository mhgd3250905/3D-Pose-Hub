# 宽距侧蹲左右移重心（t-wide-side-squat-shift）动作标准 · Flare 2.0 r2 第 1 批

机器可读版：`tools/flare2-moves-r2/standards/t-wide-side-squat-shift.json`。
来源：hark-mhgd 2026-11-21 Flare 练前热身 v2-3：宽距（约 1.9 倍肩宽）脚尖外转约 20°，侧蹲至大腿接近水平，左右移重心，每侧 5 次。
查库：`adductors-A 哥萨克蹲` 是深蹲版（屈膝侧膝角约 40°、更宽），不覆盖；本动作借用其脚跟支点与锁膝机制，改浅、改窄。

## 阶段（8 s 循环 = 左右各一次）
| 阶段 | 时间窗（s） | 要求 |
|---|---|---|
| stand 站立 | 0–0.3、3.6–4.3、7.6–8 | 宽站、脚尖外转、双臂前平举 |
| 右侧蹲 | 0.3–3.6（底部 1.6–2.3） | 重心移到右腿，右大腿接近水平，左腿伸直锁膝、脚跟着地脚尖朝上 |
| 左侧蹲 | 4.3–7.6（底部 5.6–6.3） | 镜像 |

## 数值范围（要点）
- 站距（两踝中心）67.7–75.2 cm（肩宽 37.6 cm 的 1.8–2 倍）；两脚尖外转 15–25°。
- 底部：屈膝侧大腿低于水平 -5…20°，膝角 ≥ 60°（不蹲成深哥萨克）；伸直腿膝 ≥ 174°（锁膝），脚尖高于脚跟 ≥ 25°；胸廓前倾 ≤ 35°（不前塌）。
- 双脚不离地、不滑：屈膝侧脚掌接触区漂移 ≤ 3 mm，脚不穿地。上一版左侧蹲时左脚被抬起 16 cm，本版已修（pins 0 mm）。
- 双臂前平举肘角 ≥ 170°。
