# 站姿颈腕指唤醒（t-neck-wrist-finger-wakeup）动作标准 · Flare 2.0 r2 第 1 批

机器可读版：`tools/flare2-moves-r2/standards/t-neck-wrist-finger-wakeup.json`。
来源：hark-mhgd 2026-11-21 Flare 练前热身 v2-2：颈部半圈慢绕（不后仰）+ 十指交扣腕绕 8 字 + 握拳/张指，45 秒。
头部转动和手指姿势是 V5 才有的（hub 骨架头与胸固定、V5 手是一整块），由按动作开启的 `tools/flare2-moves-r2/v5/v5r2-ext.js` 逐帧画（spec `v5r2`）；`tools/v5` 未改。

## 与清单的偏差（待开哥/mhgd 确认）
- **十指交扣 → 合掌**：交扣形状离线搜索（手-手穿插检查）最好也有 6.3 mm 穿入，沙箱近景图读起来像两只手腕交叉、手指从对面穿出来，不像交扣。按约定退回合掌（掌心相贴、指尖朝上前方）画同样的水平 8 字，近景清楚。文字/语音草稿已按画面写「合掌」。`drill-anim/lib/flare2-r2.mjs` 里的 `interlace` 手形保留未用。

## 阶段（21 s 循环 ≈ 45 秒剂量的一半）
| 阶段 | 时间窗（s） | 要求 |
|---|---|---|
| roll 颈绕 | 0.6–7.0（量测 1.4–6.2） | 右耳朝右肩 → 下巴朝胸 → 左耳朝左肩 → 回右，再回正；只在前面半圈，不后仰 |
| clasp 合掌绕腕 | 6.6–14.6（量测 8.4–13.2） | 双手抬到胸前、张指、合掌，合掌的手画两圈水平 8 字（手腕随之侧屈/屈伸），再分开 |
| 握拳/张指 | 14.6–21 | 双臂前平举、掌心朝下：握拳 → 张指 ×3，最后放下 |

## 数值范围（要点）
- 颈绕侧屈 ±30…45°（r2 ±38°），下巴朝胸前屈 25–45°（r2 34°），头后仰 ≤ 2°（构造上为 0），头绕自身长轴转 ≤ 5°（用 swing-twist 量 `headTwist`；`headRot` 在侧屈+低头组合时会算出 8.8° 假转角，不用）。
- 合掌：两手 3 mm 内接触顶点 ≥ 150，最深穿入 ≤ 5 mm（掌心软组织挤压）。
- 握拳 MCP 平均屈曲 ≥ 75°；张指 MCP ≤ -8°（微伸）、外展平均 ≥ 10°。
- 站直膝角 ≥ 165°（r2 第一次骨盆 0.948 时膝 162.4° 未过 → 骨盆 0.957），双脚不动。
