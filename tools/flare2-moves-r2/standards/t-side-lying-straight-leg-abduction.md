# 侧卧直腿外展（t-side-lying-straight-leg-abduction）动作标准 · Flare 2.0 r2 第 1 批（练后）

机器可读版：`tools/flare2-moves-r2/standards/t-side-lying-straight-leg-abduction.json`。
来源：hark-mhgd 2026-11-21 Flare 练后三档：侧卧，脚尖朝前，脚跟带动直腿上抬，骨盆不后翻。
查库：`w-clamshell-r2` 是屈膝蚌式（同一侧卧支撑姿势，本动作借用其坐标与支撑手臂），不覆盖。
**单侧示范**：左侧卧、抬右腿，App 镜像做另一侧。

## 阶段（8 s 循环 = 2 次）
| 阶段 | 时间窗（s） | 要求 |
|---|---|---|
| 上抬 | 0.3–1.4、4.3–5.4 | 上侧腿伸直，脚尖朝前、脚跟带动，略在身体线后方抬到约 35° |
| top 顶端 | 1.4–2.1、5.4–6.1 | 短停 |
| 下放 | 2.1–3.5、6.1–7.5 | 慢放，最低处离下侧腿约 6–7°（不靠在下面腿上休息） |

## 数值范围（要点）
- 上侧腿膝 ≥ 172°（r2 179.9°；第一次 163.9° —— ss-geo 腿比 v3 腿短，踝目标沿髋→踝外推 6% 后伸直）。
- 顶端两腿夹角 30–45°（r2 31°），底端 ≤ 12°（r2 6.9°）。
- 脚尖朝前不朝天：脚尖方向高于水平 ≤ 25°；脚跟带动：踝在髋后方 ≥ 1 cm（r2 12.6 cm）。
- 骨盆不后翻：骨盆转角变化 ≤ 1°（构造上固定）。
- 不穿垫 ≥ -2 mm（第一次下侧脚穿垫 10.9 mm → 骨盆抬高 12 mm），支撑前臂和下侧脚不滑 ≤ 3 mm。
