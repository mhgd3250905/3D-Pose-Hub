# Air Flare r7：张腿时裆部/臀部中线「绷平」（b2000 预览，已部署）

开哥要求：把屁股/裆部凹陷做平，像原视频角度，裤子绷住看着是平的。

## 做法（app.js 运行时 CPU 校正，crotchfix.js；模型 coach-v3r3.glb 沿用 r6 不变）
每帧在 pants 网格裆部/臀部 4909 顶点上算 LBS 后加位移，强度按两大腿夹角 50°→90° smoothstep 渐入（站姿/并腿/小角度为 0）。
- A 臀部横截面行展平：以髋轴按矢状角分 2° 行，截面相对两侧连弦的凹陷不得深于静止；只用后侧行（φ ≤ -30°），
  行边界改为 smoothstep 衰减（φ 40° 过渡 + 半径方向衰减），横向衰减 inner=0.2（原 0.6，减少两侧冒肩），宽 A=0.11 m，强度 0.8。
- B 两腿之间「膜」：在两大腿角平分方向 D 上取高度，条带内对高度场做调和（拉普拉斯，120 次迭代）插值，
  两侧大腿内侧（|u| > 0.10 m，0.04 m 渐变）与条带边缘为边界；只抬不压。替代原来的切片弦整列平移（锯齿/褶的来源）。
- 合成：B 只补 A 沿 D 未提供的部分；位移场在焊接网格上 70 次邻域平滑，限幅 7 cm。
- 骨骼矩阵未变时跳过重算（暂停/静帧零开销）。headless swiftshader 约 27 ms/帧（软件渲染，真机应快得多）。
- 默认即最佳参数；?cf=0 关闭；?cfp/cfpf/cfi/cfkA/cfkB/cfc/cfa/cfmu/cfin/cfA 可调。

## 效果
1.47 s 视频机位与近景：U 形凹口变平；1.47 s 后上方：V 变为浅弧；1.58 s：上轮的肩状鼓包消失；3.43 s 平；3.74/3.87 s 正、背面平滑无褶。
回归：托马斯 f46/f148、2000 r20 f192 仅轻微变化无新瑕疵；2000 f375、站姿 f0 像素完全一致（夹角 < 50° 不触发）。
