## 两条视频怎么结合
| 来源 | 用在哪里 |
| --- | --- |
| clipA01（00384–00612，镜像：图像左右翻转 + 解剖左右互换） | **全程主干**：站姿/交叉步 → 转身屈髋 → 左手直臂撑地 → 后腿蹬离翻身 → 右手（轴）落地 → 分腿双手倒立 → 左手上叠握右腕 → 叠掌旋转 → 开腿下落、落脚 → 起身。镜像后右手是轴手、顺时针（俯视）旋转，与 r20 时开哥要的「左手先撑、右手轴」一致。 |
| clipB（00000–00091，原生右手轴） | ① 旋转方向/转速校核：clipB 也是右手轴但逆时针转（鼻尖朝向逐帧确认，两条拟合一致），倒放后与 A 镜像同向；转速 A ≈ 580°/s（509–565 共 3 圈 1080°），B ≈ 360°/0.5 s，一致。② 叠手几何：上手握在轴手前臂上方 6 cm（B 分辨率高、手大），导出时握腕偏移用 6.5 cm、握手姿态固定在轴手掌坐标系。③ 并腿阈值（脚距 ≤ 0.28 m，小腿间距 ≥ 0.13 m 防穿插）。④ 旋转段姿态融合试验：B 倒放、按累计转角对齐，大腿/脊柱 0.4、小腿 0.25 权重 slerp 进 A；再用 A 自己的全部数据通道重拟合时，A 的 2D/深度/mask 一致拒绝了 B 的姿态（髋屈 17°→25° 回到 A），所以最终旋转段姿态以 A 为准——A 在该段数据置信度更高（同一镜头、深度一致率 77% vs B 57%）。 |

## 拟合（与 Air Flare r3 同一套 v3 骨架拟合器，加了 r21 新通道）
数据通道与权重（stageB 全序列求解，30 fps，soft_l1，f_scale 3）：
| 通道 | 用法 | 权重/尺度 |
| --- | --- | --- |
| GVHMR kp3d / SMPL-X | 初始姿态：SMPL-X 全局旋转 → v3 骨骼基旋转，根 = 骨盆 × 腿长比；A 镜像时旋转共轭 diag(-1,1,1) 并互换左右关节；GVHMR 跳变帧（A 511–513 腕身份互换/0.56 m 跳，B 20–21 脚跳）用邻帧初值 | 仅初值 |
| kp2d（身体+脚+手） | 重投影：鼻、耳(×0.5)、肩肘腕、髋膝踝、大脚趾、脚跟、掌心(×0.5，133/134) 共 21 点 | 权重 = clip(conf/5, 0, 1.2) × 质量（flagged 0.6；叠手侧别不可靠/交叉腿误标 0.3）× 帧（side_review=uncertain 0.75）；σ = 8 px |
| background_tracking.csv | frame_to_ref 仿射去相机漂移（A 镜像时用翻转共轭）；mask/深度回到原帧坐标用其逆 | — |
| VDA 深度 | 按 README 反归一化（A ×0.000341555，B ×0.000136424 每级）；在 2D 点处取 5×5 中值（只取 mask 内），左右成对（肩/肘/腕/髋/膝/踝 6 对）若差 ≥ 人物中位逆深度的 3% 则成为前后序约束：模型 z 序必须一致、余量 3 cm | 每对权重 min(1, |Δ|/8%)，尺度 3 cm，总权重 1.0 |
| mask | 人物 mask 外部距离变换（半分辨率），21 个关键点 + 9 个骨段中点投影落在 mask 外即罚 | 距离/6 px × 0.5 |
| labels.txt | 接触锁定（手/脚在地面高度 σ1 cm、零速度 σ5 mm，窗口见 fit/cfg.py；入场交叉步脚窗口用 2D 静止脚踝交叉核对 autofeet.py）、轴手=右（镜像后）、叠手握腕窗口 A 508–568（上手到轴手前臂 9 cm 处 σ3 cm）、正/背面锚点（A 517/525/532/533/541/543/545/552/553，胸朝镜头点积 ≥0.5，×20）、旋转窗并腿、不确定帧降权 | 见左 |
| 其他（沿用 Air Flare r3） | 时间加速度 σ4 cm、旋转加速度 0.15、锚定 0.5 m；腰背刚性（脊柱 0.5/0.9/1.6，前屈50/后仰28/侧弯28/扭转38/总55，颈58）；髋限位（外展64、伸展30、摆动132，×45）；离地下限；近地脚水平速度 σ1.2 cm/帧（防滑步）；叠撑段前臂离头 ≥0.15 m（σ2 cm） | — |

数据一致性（clipA 最终 vs 未加深度/mask 的同一拟合）：深度前后序一致率 70%→89%（旋转段 55%→77%）；mask 外平均 1.1→0.5 px，>10 px 的点 4.0%→1.2%；2D 中位误差 6.3→7.2 px（含新加的掌心点）。clipB：深度 68%→79%，mask 2.3→0.6 px。
深度通道在叠撑旋转段最弱（遮挡时肩部深度跟着遮挡物走，B 只有 57%），因此只做序约束不做数值深度。

导出（fit/export.py，Air Flare r3 导出 + r21 改动）：地面 y=0、原点在轴手下；30→120 fps；轴手掌心在叠撑全程跟随躯干朝向平滑转动（3 圈不靠手臂扭转）；上手握腕（姿态固定在轴手掌坐标系，腕弯一半）；落地/抬脚过渡走弧线、未锁定的脚移动时抬离地面；未锁定手指尖不穿地；手臂扭转全片 DP。

## 指标（r21.npz）
- 两手撑地间距 0.34 m（视频本身约 0.3 m；任务书 0.55 m 与 clipA 画面不符，未强改）。
- 入场最大分腿 95°；旋转段两腿夹角中位 7°。轴手叠撑期间漂移 6 mm。
- 躯干翻转（460–480）约 72°/s，低于任务书 147–186°/s；忠于 clipA 实测，未加速。
- check_move：无臂扭转跳变、无腕 >95°。

## 剩余问题
1. 入场 0.72–1.46 s 交叉步时左前臂/手与躯干穿插（最深 12 cm，原片手臂交叉在胸前）。
2. 叠撑时前臂与头部轻微贴近（最深 3 cm，修前 7.6 cm）；原片头部本就离手很近、屈肘菱形。
3. 交叉步段脚有几处单帧滑动 ≤1.9 m/s（关键点在交叉/遮挡时互换）；落地段右髋内收 60°、左髋屈 137°（6.2–6.6 s）。
4. 视频机位低（离地约 12 cm、略仰），预览默认 v0 即此机位。
5. 旋转段姿态取 A，B 的姿态融合被数据拒绝（见上）；clipB 的入场/收势（右手先撑）与右手轴+顺时针不兼容，未使用。
