# 跪姿前臂拉伸（指尖朝膝）（t-kneeling-wrist-flexor-stretch）动作标准 · Flare 2.0 新动作 r1（追加）

机器可读版：`tools/flare2-moves/standards/t-kneeling-wrist-flexor-stretch.json`。
来源：hark-mhgd 2026-11-20 16:00 追加（P1，零器械）：跪姿，双手掌心撑地、手指转向朝膝盖，臀部慢慢往后坐，掌根不离地，静止 30 秒。验收：手指明显朝膝、肘伸直、掌根贴地。
查库：现有 `forearms-A 跪姿多方向腕部摇摆` 含「指尖朝后」一段，但它是 4 个方向轮换的动态摇摆（每方向 4 下），不是 30 秒静止拉伸，故新做；`h-wall-wrist-flexor-stretch` 是站姿扶墙版。

## 阶段（8 s 循环 = 一次进出，30 秒静止是剂量）
| 阶段 | 时间窗（s） | 要求 |
|---|---|---|
| start 跪撑 | 0–0.6 | 手在肩正下方（±3 cm），手指朝膝，肘直 |
| 后坐 | 0.6–2.4 | 臀往脚跟方向坐，掌根不动 |
| hold 保持 | 2.4–6.8 | 肩在手后 7–14 cm（r1 10.5 cm），腕背伸 95–115°（r1 103°） |
| 回来 | 6.8–8 | 回到跪撑 |

## 数值范围（要点）
- 手指朝膝（膝→手方向夹角 ≥ 150°，实测 157.2°）、略外转 5–20°（实测 9.3°，两手对称；2026-11-20 修正：r1 实为内转 5°，V5 中指比 hub 掌轴偏小指侧约 13°，指向 z 0.15→0.42）；掌根贴地 ≤ 3 mm、手不滑不翻；肘 ≥ 175°；膝不滑。
- 肘铰链：前臂相对上臂扭转 ≤ 5°（r1 1.3°）、肘窝朝头侧 ≤ 30°（r1 11°）、肘带蒙皮 ≤ 5°。手指朝后所需的翻转由上臂外旋（`upperArmTwist` ±80°）和前臂旋后（手相对前臂 86–99°，提示项 ≤ 105°）分担，不经过肘（同 forearms-A-r5 的 arm-orient r2 思路）。
