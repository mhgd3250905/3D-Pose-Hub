# 面墙靠墙倒立保持（t-wall-handstand-hold）动作标准 · Flare 2.0 新动作 r1

机器可读版：`tools/flare2-moves/standards/t-wall-handstand-hold.json`。
来源：Flare 2.0 新动作清单 P1（2 个计划，三角肌中级；阶段 11/15 中级）：面墙倒立，胸腹贴近墙面，手距墙一拳，直臂顶肩，身体一条线保持。
验收（表）：手肘锁直；肩完全打开、耳在臂间；身体不塌腰；有下墙退出示意。

## 场景
- 墙面 z = 0（墙道具朝 +Z），垫子在墙前。手掌平放垫上，两手中心距 35 cm，**手指背离墙（指向房间）、略外旋约 15°、拇指在内侧**，掌根离墙约 22 cm。
- 胸腹朝墙、背朝房间；脚面绷直，只有脚尖轻贴墙。

## 阶段（8 s 循环 = 一次保持）
| 阶段 | 时间窗（s） | 要求 |
|---|---|---|
| set 站稳 | 0–0.8 | 倒立位，肩自然（+6 mm） |
| 顶肩 | 0.8–1.8 | 肩往头侧推地（+26 mm），身体整体升高 2 cm，脚尖沿墙上移 |
| hold 保持 | 1.8–7.2 | 静止 |
| 放松 | 7.2–8 | 回到起始 |

## 数值范围（要点）
- 肘 ≥ 175°；大臂与躯干长轴 ≤ 8°（肩完全打开）；头在两臂平面 ±30 mm（耳在臂间）。
- 胸廓–髋–踝 ≥ 174°，胸廓相对骨盆 −3…8°（不塌腰），膝 ≥ 172°；向墙微倾 3–10°。
- 脚尖贴墙 −1…3 mm，躯干离墙 20–90 mm，掌根离墙 170–250 mm；头离垫 ≥ 80 mm。
- 手：手腕→中指根（水平）与「背离墙」夹角 ≤ 25°；外旋 5–25°、左右差 ≤ 5°；拇指尖在手腕内侧 ≥ 20 mm；肘窝朝手指一侧偏内（与手指方向 ≤ 75°）；肘弯曲方向与肘窝偏差 ≤ 10°（不拧）；手相对前臂扭转 ≤ 65°。

## 制作参数（r1）
- 倒立用骨盆基底 `up: [0,-1,0]`、`front: [0,0,-1]`，绕 X 倾 −6.2°（手腕 z = 0.25）；腿用 `free`（frame hips）站姿踝点 + 脚绷 62°；肩胛上提 `shoulders.shift`（`v5.scapulaShift`）。

## r1 手朝向修正（2026-11-20，开哥看预览「手的朝向不对」）
- 根因：r1 让手指朝墙（`finger: [±0.25, -1]`，世界 −Z）。hub 地面手把「手掌长轴」转到给定方向、掌心朝下，手的左右手性是固定的；在这个倒立坐标（身体左 = +X、胸朝 −Z）里，手指朝墙 ⇒ 拇指在外侧，等于两只手掉了个头（前臂多拧约 90°、肘窝朝墙）。V5 实测：中指根方向与「朝墙」0.5°，拇指在手腕外侧 72 mm。
- 正确做法（面墙倒立）：手指背离墙、指向房间，略外旋，拇指在内侧，掌根靠墙一侧（CrossFit Journal 2015「The hands should be flat on the ground and pointed away from the wall with the fingers splayed」；推墙走上去时手本来就是这个朝向）。
- 改动：`finger: [±0.035, 1]`（hub 掌轴；V5 中指根比 hub 掌轴再往小指侧偏约 13°，实测外旋 15.5°）；整条手臂外旋 `upperArmTwist = elbowTwist = ∓140°`（肘仍是纯铰链），肘极点 `poleUp: [±0.9, 0, 0.72]` 放在肘窝的反面（肘尖一侧），残余 1.5° 屈肘朝肘窝弯；手往墙移到 z = 0.25、倾角 −6.2° 保证脚尖贴墙、胸离墙 ≥ 20 mm。
- 掌根离墙：这个模型的胸廓厚度下，倾角 ≥ 3° 且胸不碰墙时掌根最近约 18 cm；r1 修正版取 22 cm（资料：约一个手掌长 / 15 cm 左右）。若开哥要更近（约一拳），胸要几乎贴墙、倾角更小，需开哥定。

## 需开哥判断
- **表中「有下墙退出示意」没做进动画**（只有保持段；退出写在提示语和注意事项里）。走下墙/侧翻需要手脚交替走动，建议另出一个短动作或在 App 里用文字/图示，开哥定。
- 顶肩时身体升 2 cm，脚尖随之沿墙上滑 2 cm（真实情况也会这样）。
