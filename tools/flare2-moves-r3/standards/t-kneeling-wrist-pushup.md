# 跪姿手腕俯卧撑 t-kneeling-wrist-pushup — 动作量化标准（Flare 2.0 r3 第 2a 批，AI 草稿）

来源：Flare 2.0 练后 专项补强（Google 表 1aCseEk4vslsG-QKb-zsZwg30amvoYh5tMxzy6p9n8vA）。剂量（草稿）：10 次慢速，1 组。

## 动作要点
- 跪姿支撑：双膝着垫，膝-髋-肩一条线，手在肩下、手指朝前，**全程锁肘**。
- 双手同时：手指压地，把掌根抬到指根（只剩手指贴垫），顶端停约 0.5 秒，再用 **3 秒**慢慢放平。
- 指根（掌指关节）是支点，不移动；手指始终平贴垫子（V5 手指在指根处向后弯，弯的角度跟掌根抬起同步）。
- 手臂伸直不动，掌根抬起时肩膀随手腕一起升高（身体以膝为轴整体转动），不是耸肩或屈肘。

## 量化（沙箱 V5 测量）
- 锁肘：两肘最小角 ≥ 175°。
- 顶端：V5 掌骨线（腕关节 → 中指掌指关节中心）抬起 50–65°（动画 58°）；放平时 −8…6°。左右差 ≤ 3°。
- 慢放：从顶端 97% 降到 3% 用时 ≥ 2.2 秒（3 秒缓起缓停段）；顶端停顿 ≥ 0.4 秒；每循环 2 次。
- 手指贴地：手最低点 −2…6 mm（全程）；中指掌指关节中心漂移 ≤ 6 mm；手指方向偏离正前 ≤ 12°。
- 身体：膝-髋-肩线偏离 ±25 mm；膝着垫 −2…6 mm；肩在手上方（平贴时侧视 −6…6 cm）。

## 动画
10 秒循环 = 2 次（0.4 平贴 / 1.0 抬起 / 0.5 顶端 / 3.0 慢放 / 0.1）。双手同时，左右对称，不需要镜像。
