# 前臂侧桥（直腿）t-forearm-side-plank — 动作量化标准（Flare 2.0 r3 第 2a 批，AI 草稿）

来源：Flare 2.0 练后 专项补强（Google 表 1aCseEk4vslsG-QKb-zsZwg30amvoYh5tMxzy6p9n8vA）。剂量（草稿）：每侧静态 20 秒，1 组。
与已有 h-short-side-plank（屈膝短杠杆）不同：直腿、全长杠杆。

## 动作要点
- 左侧着地（示范一侧；App 镜像另一侧）：左前臂平放垫上、朝前，**手肘在肩正下方**，上臂竖直。
- 双腿伸直并拢，下面的脚外侧着地；**髋抬高**，头-躯干-腿一条直线；胸口朝正前，不前扑不后倒。
- 上面的手臂伸直指天。静态保持。

## 量化（沙箱 V5 测量）
- 肘在肩正下方：水平偏差 ≤ 4 cm；撑地上臂偏离竖直 ≤ 12°。
- 身体线：髋偏离肩-踝线 −20…+30 mm；头颈与躯干夹角 ≤ 20°；膝 ≥ 172°；胸前方向偏离水平 ±15°。
- 着地：前臂、撑地手 −2…5 mm；脚 −2…5 mm；肘支点漂移 ≤ 3 mm；静态（髋偏离全程变化 ≤ 2 mm）。

## 动画
8 秒循环，静态（高亮脉动提示保持）。只示范左侧着地，App 镜像出右侧。
