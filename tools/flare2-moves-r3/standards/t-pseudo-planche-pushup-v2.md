# 伪俄挺俯卧撑（指尖朝外） t-pseudo-planche-pushup-v2 — 动作量化标准（Flare 2.0 r3 第 2b 批，AI 草稿）

来源：Flare2（Google 表 1aCseEk4vslsG-QKb-zsZwg30amvoYh5tMxzy6p9n8vA）伪俄挺俯卧撑新版：**手指朝外 45–90°，绝不朝后**。剂量（草稿）：6 次 × 3 组。
新 id；r1 的 t-pseudo-planche-pushup（指尖约 100°、略朝后）一字不改。除手指方向外，身体、前倾幅度、节奏、脚在脚尖上滚动都与 r1 相同（spec 抄自 r1）。

## 动作要点
- 俯卧撑位，手放腰侧偏上（下肋旁），**指尖朝外约 60–75°**（拇指朝头侧），身体整体前倾，顶端肩超过手腕约 12 cm（入门幅度，2026-11-21 开哥定）。
- 屈肘时肘贴身体向后，下放到约 90°，肩继续前移（底端约 19 cm），再推回直臂；全程头到脚一条线，脚尖在垫上滚动不滑。
- 顶端肩胛推开下沉（V5 scapulaShift）。

## 量化（沙箱 V5 测量）
- 指尖外转（V5 中指根方向相对正前，两手）45–90°，左右差 ≤ 6°；掌心平贴偏差 ≤ 20°。
- 顶端锁肘 ≥ 175°；底端肘 80–95°；肩超过手腕：顶端 10–13 cm、底端 15–22 cm、全程 ≥ 10 cm。
- 手位 0.35–0.6（肩→髋连线）；髋 −15…20 mm；胸廓–髋–踝 ≥ 175°；膝 ≥ 172°；肘贴身 ≤ 20°；腕背伸 ≤ 100°（指尖朝外后比 r1 的 88.6° 略大）。
- 底端肘窝朝向手指一侧（肘窝与手指方向 ≤ 90°）；顶端直臂时的肘窝朝向只作提示（直臂时由微屈平面决定）。
- 手掌不滑 ≤ 2 mm、不翻 ≤ 2°；脚尖接触区 ≤ 5 mm；胸离垫 ≥ 50 mm；每循环 2 次。

## 动画
8 秒循环 = 2 次（0.4 s 顶端、1.5 s 下放、0.3 s 底端、1.2 s 推起、0.6 s 顶端 ×2）。左右对称，不需镜像。

## 需开哥判断
- 指尖外转角：现在约 72°（命令 60°，V5 手形再外转约 12°）。要更朝外（接近 90°）或更朝前（接近 45°）都只改一个数（spec 里 `FO`）。
- 顶端直臂时肘窝朝后内侧（提示项 132°，r1 同样的手臂设定）；底端屈肘时肘窝朝前外（84°）。样片里看手臂是否有「拧毛巾」感。
