# 直臂侧桥转换 t-straight-arm-side-plank-switch — 动作量化标准（Flare 2.0 r3 第 2a 批，AI 草稿）

来源：Flare2（Google 表 1aCseEk4vslsG-QKb-zsZwg30amvoYh5tMxzy6p9n8vA）。剂量（草稿）：每侧 6 次，左右交替（1 次 = 左右各转一次），1 组。

## 动作要点
- 直臂平板：手在肩下，锁肘，身体一条线，脚尖撑地。
- **先锁肘再转**：撑地手臂保持伸直，整个身体一起转成直臂侧桥——撑地肩叠在手正上方，上面的手指向天花板，髋保持高、身体一条线；双脚在原地转到脚侧着地（前后错开）。
- 停约 1 秒，转回平板，再转另一侧。**不做俯卧撑**（胸口不下沉，两臂始终伸直）。

## 量化（沙箱 V5 测量）
- 着地手臂全程锁肘 ≥ 172°（平板时双臂 ≥ 175°）。
- 侧桥：撑地肩在手正上方水平偏差 ≤ 6 cm；身体转满（胸前方向偏离水平 ±15°）；上手偏离竖直 ≤ 20°。平板：胸口朝下（胸前方向 ≤ −60°）。
- 全程身体一条线：髋偏离肩-踝线 −30…+35 mm；膝 ≥ 170°。
- 手不穿地、撑地手不滑（≤ 3 mm）；脚不穿地、双脚始终着地（较高那只脚最低点 ≤ 8 mm）。脚在原地以脚掌/脚侧为轴转动（不计入支点漂移）。

## 动画
12 秒循环 = 左右各一次：0–0.65 平板 / 0.65–2.3 转到左手 / 2.3–3.3 侧桥 / 3.3–4.85 转回 / 4.85–6.0 平板；6–12 同样转到右手。上手在转身开始时离地、转回结束时落地（沿体侧弧线）。左右都有，不需要镜像。
