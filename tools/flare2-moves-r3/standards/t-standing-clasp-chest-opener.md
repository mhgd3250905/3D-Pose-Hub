# 背后十指交扣扩胸 t-standing-clasp-chest-opener — 动作量化标准（Flare 2.0 r3 第 2b 批，AI 草稿）

来源：Flare2（Google 表 1aCseEk4vslsG-QKb-zsZwg30amvoYh5tMxzy6p9n8vA）背后十指交扣扩胸（站姿）。剂量（草稿）：保持 20 秒 × 2 次。新 id。

## 动作要点
- 站直，双脚与髋同宽。双手在背后十指交扣（掌心相对），先轻放在下背，肘微屈。
- 手臂伸直，交扣的手向后下方拉离身体（肩后伸约 40°），肩胛夹紧、下沉，挺胸（上背轻微后伸），头中立，不前倾、不耸肩；保持，再放松回起始。

## 量化（沙箱 V5 测量）
- 保持段：肩后伸（两臂）30–55°；起始 ≤ 30°；手臂伸直 ≥ 170°。
- 肩胛后缩 ≤ −8 mm（肩关节相对胸廓向后）；不耸肩（肩关节相对胸廓高度 ≤ 0）。
- 胸廓前后倾 −12…3°（不前倾）；胸廓相对骨盆后伸 −12…0°；头与胸廓 ≤ 15°。
- 交扣：两手穿插深度 ≤ 8 mm、接触顶点 ≥ 60；脚 −2…3 mm、不滑 ≤ 3 mm。

## 动画
8 秒循环：0.8 s 起始、1.5 s 伸直后拉、4.0 s 保持、1.3 s 放松。左右对称，不需镜像。

## 手形
V5 手指姿势 = r2 搜索过的 `interlace` 交扣手形（右手比左手沿手指横向高 15 mm、各绕掌心法线转 10°），r3 2b 把中节/末节再弯 +38°/+22° 让手指包住对侧手背、
半掌距 20.4 → 23.5 mm（穿插 5.9 mm）。r2 在胸前做同一个手形时近景读起来像手腕交叉（所以 r2 改成了合掌）；本动作手在背后、镜头在侧后方，近景仍需在样片里确认。

## 需开哥判断
- 交扣近景是否像「十指交扣」：如果像手腕交叉或手指穿出来，备选是「一手握住另一手的四指」（手形 hook，不穿插），需要开哥定。
