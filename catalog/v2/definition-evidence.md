# 六动作定义补全：证据、推断与待审项

2026-10-21，本次只更新 `actions/*.json` 的 `definition`。动作名、主要点文本、剂量和已对齐的节奏均保持，source/spec/voice 与制作记录不变。注意部位、通用禁用条件、协同标签及动作关系已有具体双语草稿，`review: pending` 表示尚待审阅，不能再把它们统称为“缺数据”。

## 采用的证据

仓库证据以 `catalog/catalog.json` 中的稳定 ID、动作名称、肌群、体位、器械、level 和旧 `alternative` 为基础；运动形态再读取对应 `drill-anim/specs/<id>.js`。标签词表见 `catalog/taxonomy.json`，肌群映射见 `docs/anatomy-assets.md`。旧 level 只能作背景，不能单凭数字证明动作之间的难度顺序。

本次检索仅使用以下权威一手资料，访问日期为 2026-10-21：

- [AAOS Spine Conditioning Program](https://www.orthoinfo.org/recovery/spine-conditioning-program/)：疼痛应停止并咨询；伤后或术后训练需按专业人员安排。髋桥涉及臀部、腿后侧与躯干控制，鸟狗式涉及对侧肢体与平衡控制。
- [AAOS Hip Conditioning Program](https://www.orthoinfo.org/recovery/hip-conditioning-program/)：训练和拉伸应按恢复目标选择，疼痛不能忽视。该来源不等同于对本仓库蛙式大幅度轨迹的专项临床批准。
- [NHS Strength exercises](https://www.nhs.uk/live-well/exercise/strength-exercises/)：稳定、防滑、无轮椅具；弯举轻重量、上臂靠身、缓慢放下，也可坐姿进行。其椅具建议不代表任意家用椅子都适合站上去；本仓库上步源 spec 另明确牢固支撑面要求。

新增禁用条件是“动作诱发疼痛应停止”和“已有临床活动/负重限制时先取得许可”等通用筛查；上步另有环境不满足就不执行的条件。**没有杜撰某疾病、某术后人群的绝对禁忌，也没有宣称这份筛查已覆盖全部医学情形。** 条目按各动作受力部位表述属于编辑应用，仍须专业人员确认边界。

| `h-chair-step-up` | 替代/降阶 `h-squat`；进阶候选 `h-bulgarian` | 深蹲替代来自旧目录；去掉登高要求作为降阶是教学推断。保加利亚分腿蹲的单侧主力、后脚抬高和旧 level3 可从源验证，列为臀腿力量目标的进阶候选，不是“更高台阶”版本。协同腿后侧、小腿、髋外展肌是动作/稳定角色推断。 |

| `s-frog` | 替代 `s-butterfly` / `h-adductor-rock`；降阶候选 `s-butterfly` / `h-butterfly-active` | 蝴蝶式来自旧明确替代；四足侧伸后摇保留内收肌后摇目标。坐姿/仰卧蝴蝶去掉四足宽膝支撑要求，但仍需个体适应性审核。腹部、竖脊肌标签只表示后摇时躯干稳定，不是额外腰部拉伸目标。 |
| `h-catcow-quad` | 替代/降阶 `o-seated-catcow`；进阶候选 `w-bird-dog` | 坐姿源可验证同一猫牛屈伸模式且手放膝上。鸟狗是进一步的四足肢体离地稳定目标，不是猫牛更大屈伸。三角肌、前臂标签表示承重与腕稳定，不能因此改成举肩或腕屈伸动作。 |

所有 `synergistMuscles` 使用现有词表，且不与同条 `activeMuscles` 重复；它们包含姿势稳定角色。这里没有新增肌电量化结论或要求额外高亮。主要与协同角色、中文表达及英文翻译都必须经运动专业编辑审核。

## 真正仍缺的独立动作关系

以下空数组保留为明确的**独立目标 ID 缺口**，不是笼统“未审核”：

| 动作 | 缺口 | 当前可描述、但不能伪造为新 ID 的调整 |
|---|---|---|
| `w-dead-bug` | 独立降阶 ID | 同动作缩小手脚幅度、单个肢体或腹部稳定入门；仓库没有对应独立演示 ID。 |
| `h-db-curl` | 独立降阶及进阶 ID | 减重/坐姿/逐步加重属于同动作变式，当前没有对应独立坐姿或进阶弯举包；不能用同 ID 自指绕过关系字段。 |
| `glute-max-A` | 经验证的同模式独立进阶 ID | 当前未找到经过比对确认的高负荷单腿臀桥专用 ID。 |
| `s-frog` | 经验证的同模式独立进阶 ID | 不把更深强压、横劈叉或不同目标的力量动作自动当作蛙式进阶。 |

这些调整的提示文字已经进入各动作 `editorialNotes`，以便继续编制，而非留成不明空白。后续若要让 App 结构化选择同 ID 的负重/体位变式，需要明确变式字段和独立可用素材；本轮没有在 schema 外私加字段。

## 发布与审核边界

目前本轮仅有六个试点 v2 包。上述关联目标均不是本轮已验收可发布的 v2 包；`h-biceps-self` 连旧 catalog 目标条目也尚未建立。**关系列表代表源动作候选，不授予 SDK 自动切换目标或取旧模型视频的资格。** 消费端/发布清单必须先检查目标包存在、与当前模型版本一致且实际可用；缺目标时不得静默回退弃用模型。

必要审核仍包括：通用禁用条件是否适用于该动作及产品场景、是否需补充具体病况/术后边界、主要/协同肌群角色、注意部位、中英文措辞，以及关系候选的目标/负荷/器械差异。`editorialReview`、`cautions.review`、`contraindications.review` 全部保留 pending，无审阅人、时间和真实证据就不能标 pass。专业审核未做是审批状态，不能当成对应具体草稿没有数据。
