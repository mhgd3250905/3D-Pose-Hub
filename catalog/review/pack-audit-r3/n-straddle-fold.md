## 4. 指导文字（教练口吻）
- purpose：拉伸大腿内侧和后侧 → 拉开大腿内侧和后面
- 要点 改前：背部拉长，上身慢慢往前倾；坐在垫子上，双腿伸直分开，脚尖和膝盖朝上。；保持不动，慢慢呼吸，每次呼气再放松一点。；别来回颠，有拉伸感就够，别拉到疼。
- 要点 改后：背拉长，上身慢慢往前倾；坐在垫子上，两腿伸直分开，脚尖和膝盖朝上。；就停在这儿，慢慢喘气，每次呼气再松一点。；别一下一下往下压，有拉的感觉就够，别拉到疼。
- 常见错误 改前：弓背去够地面；膝盖往里倒；憋气或来回颠
- 常见错误 改后：弓背去够地；膝盖往里倒；憋气或一下一下往下压
- 注意事项 改前：拉伸处疼时幅度小一点，还疼就停
- 注意事项 改后：拉的地方疼就少往前倾点，还疼就停
- 相位口令：慢慢前倾 / 保持，慢慢呼气 / 呼气再前倾 → 慢慢前倾 / 停住，呼气 / 呼气再前倾
