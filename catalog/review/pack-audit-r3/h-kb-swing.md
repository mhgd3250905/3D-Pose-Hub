## 4. 指导文字（教练口吻）
- purpose：用髋部发力练臀部和大腿后侧的爆发力 → 靠屁股往前一顶的劲，练屁股和大腿后面的爆发力
- 要点 改前：髋部猛地往前推，让手臂把壶铃荡起来；背保持平直，臀部往后推，壶铃荡到两腿之间。；顶端站直夹臀，身体不后仰。
- 要点 改后：屁股猛地往前一顶，让壶铃自己荡起来；背挺平，屁股往后坐，壶铃荡到两腿中间。；顶上站直、夹紧屁股，人别往后仰。
- 常见错误 改前：用手臂抬壶铃；下蹲代替臀部往后推；弓背
- 常见错误 改后：用手臂把壶铃抬起来；蹲下去，不是屁股往后坐；弓背
- 注意事项 改前：腰疼时停止，先用轻壶铃；周围有人或东西时不要做
- 注意事项 改后：腰疼就停；先两手抱一个轻壶铃练熟再单手；周围有人或东西就别做
- 相位口令：推髋 / 站直 / 回摆 → 往前顶 / 站直 / 往回荡
