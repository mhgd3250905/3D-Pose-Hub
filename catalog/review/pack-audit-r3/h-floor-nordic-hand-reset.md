## 4. 指导文字（教练口吻）
- purpose：练大腿后侧，学会慢慢控制身体往前倒 → 练大腿后面，学会慢慢刹住身体往前倒
- 要点 改前：跪姿固定脚跟，身体一条直线慢慢往前倒；用大腿后侧控制往下的速度。；倒到底双手撑地，屁股往后坐再推回跪直。
- 要点 改后：跪好、脚后跟勾住，身子一条直线慢慢往前倒；大腿后面使劲刹住，越慢越好。；倒到底两手撑地，屁股往后坐，再推回跪直。
- 常见错误 改前：一开始就弯腰；倒得太快
- 常见错误 改后：一开始就撅屁股、弯着腰往下；倒得太快
- 注意事项 改前：大腿后侧有拉扯感或疼时停止，先从小幅度做起；脚跟固定不牢时不要做，膝下垫软垫
- 注意事项 改后：大腿后面发紧发疼就停；倒不了多远就先只倒一小段；脚后跟没勾牢别做，膝盖底下垫软垫
- 相位口令：慢慢前倒 / 双手撑地 / 推回跪直 → 慢慢前倒 / 手撑地 / 推回跪直
