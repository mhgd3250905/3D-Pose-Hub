## 4. 指导文字（教练口吻）
- purpose：练下腹部 → 练肚子下面那一块
- 要点 改前：用下腹把屁股卷离垫子，膝盖靠向胸口；双手压地，上背贴住垫子。；慢慢放回，脚别掉下去。
- 要点 改后：用肚子把屁股卷离垫子，膝盖往胸口靠；两手压地，上背贴住垫子。；慢慢放回来，脚别砸下去。
- 常见错误 改前：甩腿借力；放回时腰拱起来
- 常见错误 改后：甩腿借劲；放回来时腰拱起来
- 注意事项 改前：腰不舒服时幅度小一点，还疼就停
- 注意事项 改后：腰不舒服就卷小点，还疼就停；卷不起来就只把膝盖往胸口收
- 相位口令：卷起 / 停一下 / 慢放下 → 卷起来 / 停一下 / 慢慢放
