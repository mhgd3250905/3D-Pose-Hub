## 4. 指导文字（教练口吻）
- purpose：拉伸腰侧和背部侧面 → 拉开腰侧和背的侧面
- 要点 改前：手臂举高，身体往另一侧弯，髋不动；双脚与髋同宽，另一只手放在大腿外侧。；保持不动，慢慢呼吸，每次呼气再放松一点。；别来回颠，有拉伸感就够，别拉到疼。
- 要点 改后：手臂举高，身子往另一边弯，胯别动；两脚跟胯一样宽，另一只手放在大腿外面。；就停在这儿，慢慢喘气，每次呼气再松一点。；别一下一下往下压，有拉的感觉就够，别拉到疼。
- 常见错误 改前：身体前倾或扭转；髋部往侧面甩出去；憋气或来回颠
- 常见错误 改后：身子往前倒或扭了；胯往旁边甩出去；憋气或一下一下往下压
- 注意事项 改前：腰背或肩膀疼时幅度小一点，还疼就停
- 注意事项 改后：腰背或肩膀疼就弯小点，还疼就停
- 相位口令：往侧边弯 / 保持，慢慢呼气 / 呼气再放松 → 往旁边弯 / 停住，呼气 / 呼气再松
