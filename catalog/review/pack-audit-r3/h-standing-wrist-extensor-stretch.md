## 4. 指导文字（教练口吻）
- purpose：拉伸前臂靠手背的一侧，让手腕更放松 → 拉开小臂靠手背那面，手腕更松
- 要点 改前：手臂伸向前方，掌心朝下，手腕慢慢往下弯；手肘伸直但不锁死，不用另一只手压。；肩膀放松，每次停一下再慢慢放松手腕。
- 要点 改后：手臂伸到前面，掌心朝下，手腕慢慢往下弯；手肘伸直别锁死，不用另一只手压。；肩膀放松，停一下再慢慢松开手腕。
- 常见错误 改前：耸肩；用力硬压
- 常见错误 改后：耸肩；硬掰
- 注意事项 改前：出现疼痛时放松，只拉到舒服的程度
- 注意事项 改后：拉到舒服就行，疼就松一点
- 相位口令：手腕下弯 / 保持住 / 慢慢放松 → 手腕往下弯 / 停住，喘气 / 慢慢松开
