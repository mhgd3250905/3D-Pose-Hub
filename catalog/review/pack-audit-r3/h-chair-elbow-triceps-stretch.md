## 4. 指导文字（教练口吻）
- purpose：拉伸上臂后侧和腋下 → 拉开大臂后面和腋下
- 要点 改前：手肘搭稳椅背，臀部往后让胸口下沉；双肘弯着，手放在后颈附近，别碰头。；停住不动，慢慢呼吸。；每次呼气再放松一点，别来回颠。
- 要点 改后：手肘搭稳椅背，屁股往后推，胸口往下沉；两肘弯着，手放在后脖子附近，别碰头。；就停在这儿，慢慢喘气。；每次呼气再松一点，别一下一下往下压。
- 常见错误 改前：用手压头或脖子；憋气；来回颠着往下压
- 常见错误 改后：用手压头或脖子；憋气；一下一下往下压
- 注意事项 改前：肩膀疼时下沉少一点；用结实、不带轮子的椅子
- 注意事项 改后：肩膀疼就沉少点；用结实、不带轮子的椅子
- 相位口令：慢慢沉下去 / 保持，慢慢呼气 / 呼气再沉一点 → 慢慢沉下去 / 停住，呼气 / 呼气再松
