## 4. 指导文字（教练口吻）
- purpose：练大腿向内转的力量和控制，让髋更灵活 → 练后面那条腿的胯往里转的劲，让胯转得更开
- 要点 改前：坐直，后腿膝盖贴地，把小腿和脚抬起；前腿小腿横在身前，双手放在膝盖上。；顶上停一下，再慢慢放下。
- 要点 改后：坐直，后腿膝盖贴地，把小腿和脚抬起来；前腿小腿横在身前，两手放在膝盖上。；顶上停一下，再慢慢放下。
- 常见错误 改前：身体往后仰或歪向一边来抬脚；后腿膝盖跟着离地
- 常见错误 改后：身子往后仰或歪着去抬脚；后腿膝盖也跟着离地
- 注意事项 改前：髋或膝不舒服时抬低一点，还疼就停
- 注意事项 改后：胯或膝盖不舒服就抬低点，还疼就停；抬不起来就两手撑在身后，能抬一点是一点
- 相位口令：抬小腿 / 停一下 / 放下来 → 抬小腿 / 停一下 / 放下来
