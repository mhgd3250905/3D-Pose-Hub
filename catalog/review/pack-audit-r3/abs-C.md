## 4. 指导文字（教练口吻）
- purpose：练腹部，提升在双杠上撑住时抬腿的能力 → 练肚子，在双杠上撑住身体把腿抬起来
- 要点 改前：手臂撑直，卷起肚子把膝盖抬高；膝盖抬到比髋高一点，停一下。；慢慢放下，腿不要甩。
- 要点 改后：手臂撑直，卷起肚子把膝盖往上提；膝盖提到比胯高一点，停一下。；慢慢放下来，腿别甩。
- 常见错误 改前：甩腿借力；肩膀往耳朵方向塌
- 常见错误 改后：甩腿借劲；肩膀往耳朵那儿塌
- 注意事项 改前：肩前面夹着疼时，抬低一点或换简单版本
- 注意事项 改后：肩膀前面夹着疼就抬低点，或者换躺着举腿；做不满 8 个就先只练双杠撑住
- 相位口令：抬腿 / 停一下 / 慢慢放下 → 提膝 / 停一下 / 慢慢放
