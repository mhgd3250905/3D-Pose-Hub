## 4. 指导文字（教练口吻）
- purpose：拉伸胸口和肩膀前侧 → 拉开胸口和肩膀前面
- 要点 改前：双前臂贴住门框，身体慢慢往前穿过门口；前后脚站稳，脚不动。；停住不动，慢慢呼吸。；每次呼气再放松一点，别来回颠。
- 要点 改后：两条小臂贴住门框，身子慢慢往门里探；前后脚站稳，脚别动。；就停在这儿，慢慢喘气。；每次呼气再松一点，别一下一下往下压。
- 常见错误 改前：腰往前挺代替打开胸口；憋气；来回颠着往下压
- 常见错误 改后：肚子往前挺，胸口没打开；憋气；一下一下往下压
- 注意事项 改前：出现疼痛时放松，只拉到舒服的程度；肩前侧夹着疼时，缩小幅度或换简单版本
- 注意事项 改后：拉到舒服就行，疼就松一点；肩膀前面夹着疼就往前少探点，或把手臂放低
- 相位口令：慢慢往前 / 保持，慢慢呼气 / 呼气再放松 → 慢慢往前探 / 停住，呼气 / 呼气再松
