## 4. 指导文字（教练口吻）
- purpose：拉伸大腿内侧 → 拉开大腿内侧
- 要点 改前：膝盖往两边打开，臀部慢慢往后坐；前臂撑地，脚尖朝外，背放平。；保持不动，慢慢呼吸，每次呼气再放松一点。；别来回颠，有拉伸感就够，别拉到疼。
- 要点 改后：膝盖往两边打开，屁股慢慢往后坐；小臂撑地，脚尖朝外，背放平。；就停在这儿，慢慢喘气，每次呼气再松一点。；别一下一下往下压，有拉的感觉就够，别拉到疼。
- 常见错误 改前：硬压髋部追求更大幅度；憋气或来回颠
- 常见错误 改后：硬压胯想分更开；憋气或一下一下往下压
- 注意事项 改前：膝盖下面垫软垫，膝盖不舒服就别再分开；大腿内侧疼时坐浅一点，别让别人帮你压
- 注意事项 改后：膝盖下面垫软垫，膝盖不舒服就别再分开；大腿内侧疼就少往后坐点，别让别人帮你压
- 相位口令：臀部后坐 / 保持，慢慢呼气 / 呼气再放松 → 屁股往后坐 / 停住，呼气 / 呼气再松
