## 4. 指导文字（教练口吻）
- 名称：90/90坐姿髋部拉伸 → 90/90 坐姿拉胯
- purpose：拉伸前腿的臀部和髋外侧 → 拉开前腿那边的屁股和胯外侧
- 要点 改前：背挺直，身体朝前腿小腿上方慢慢前倾；前腿和侧腿都弯成直角，胸口对着前腿。；保持不动，慢慢呼吸，每次呼气再放松一点。；别来回颠，有拉伸感就够，别拉到疼。
- 要点 改后：背挺直，上身朝前腿小腿上方慢慢前倾；前腿和侧腿都弯成直角，胸口对着前腿。；就停在这儿，慢慢喘气，每次呼气再松一点。；别一下一下往下压，有拉的感觉就够，别拉到疼。
- 常见错误 改前：弓背往下压；臀部离地歪向一边；憋气或来回颠
- 常见错误 改后：弓背往下压；屁股离地歪向一边；憋气或一下一下往下压
- 注意事项 改前：膝盖疼时少倾一点或垫高臀部，还疼就停
- 注意事项 改后：膝盖疼就少倾点或屁股下面垫高，还疼就停
- 相位口令：身体前倾 / 保持，慢慢呼气 / 呼气再放松 → 慢慢前倾 / 停住，呼气 / 呼气再松
