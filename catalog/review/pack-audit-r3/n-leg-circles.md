## 4. 指导文字（教练口吻）
- purpose：练髋部往各个方向的控制 → 让胯往各个方向都活动开，腿画圈时胯不晃
- 要点 改前：骨盆和另一条腿不动，直腿慢慢画圈；仰卧，手臂放在身体两侧，掌心贴地。；画一圈再交叉算 1 次，骨盆要转就停。
- 要点 改后：胯和另一条腿不动，直腿慢慢画圈；仰躺，两手放在身边，手心贴地。；画一圈再交叉算 1 下，胯一要转就停。
- 常见错误 改前：圈画太大，骨盆跟着晃；抬腿时腰离开地面
- 常见错误 改后：圈画太大，胯跟着晃；抬腿时腰离开地
- 注意事项 改前：髋部疼或响得不舒服时圈画小一点，还疼就停
- 注意事项 改后：胯疼或响得不舒服就把圈画小点，还疼就停
- 相位口令：画圈再交叉 / 停住 / 收回来 → 画圈再交叉 / 停住 / 收回来
