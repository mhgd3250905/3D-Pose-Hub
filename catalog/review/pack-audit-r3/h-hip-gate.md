## 4. 指导文字（教练口吻）
- purpose：活动髋部，让腿往外打开和转动更灵活 → 把胯活动开，腿往外打开、转起来更顺
- 要点 改前：膝盖抬到髋的高度，往外画一圈再放下；一手扶椅背，骨盆和上身朝前不转。；画一圈算 1 次，下一次反方向画回来。
- 要点 改后：膝盖抬到跟胯一样高，往外画一圈放下；一手扶椅背，肚脐和胸口一直朝前。；画一圈算 1 下，下一下反着画回来。
- 常见错误 改前：身体跟着转或往一边倒
- 常见错误 改后：腿一转，身子也跟着转或往一边倒；甩着腿画，太快
- 注意事项 改前：髋不舒服时减小幅度，仍痛就停止；椅子会滑动时换一把稳固、不带轮子的
- 注意事项 改后：胯不舒服就把圈画小点，还疼就停；椅子会滑就换把稳的、不带轮子的
- 相位口令：抬膝 / 画圈 / 放下 → 抬膝 / 画圈 / 放下
