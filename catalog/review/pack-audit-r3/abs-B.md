## 4. 指导文字（教练口吻）
- purpose：练腹部和抬腿的力量，提升撑住身体的能力 → 练肚子和抬腿的劲，两手把自己撑离地面
- 要点 改前：手臂撑直，膝盖抬到胸前；肩膀往下压，别耸肩。；做得稳了，再试着两腿轮流往前伸直。
- 要点 改后：手臂撑直，膝盖往胸口收；肩膀往下沉，离耳朵远点，别耸肩。；撑稳了再试着一条腿往前伸直，两条腿轮流。
- 常见错误 改前：耸肩，脖子缩起来；膝盖往下掉
- 常见错误 改后：耸肩，脖子缩没了；膝盖一点点往下掉
- 注意事项 改前：手腕疼或发麻时停下；先活动手腕再做
- 注意事项 改后：手腕疼或发麻就停，做之前先转转手腕；撑不起腿就脚尖点地，先只把身体撑住
- 相位口令：撑起团身 / 保持住 / 慢慢放下 → 撑起收腿 / 撑住 / 慢慢放下
